# 📁 AI Chat Folders — 功能说明

## 1. 概述

**AI Chat Folders** 是一款浏览器扩展，旨在为流行的 AI 聊天平台（ChatGPT、Gemini、Claude、DeepSeek）提供类似文件管理器的文件夹系统，帮助用户将成百上千的对话归类整理，极大提升工作效率。

- 扩展仅在本地存储元数据（文件夹结构、聊天引用），**绝不复制或上传任何对话内容**。
- 支持在各大 AI 平台的侧边栏或上下文菜单中无缝集成，操作流畅，视觉统一。

---

## 2. 核心功能

### 2.1 文件夹管理

- **创建顶级文件夹**  
  点击扩展面板顶部的“➕”按钮，输入名称并选择颜色即可创建。
- **创建子文件夹**  
  任意文件夹卡片上的“➕”按钮可为其添加子文件夹，支持无限嵌套。
- **编辑文件夹**  
  点击文件夹卡片上的“✏️”按钮，可修改名称或颜色。
- **删除文件夹**  
  点击“🗑️”按钮，会弹出确认提示。删除后，该文件夹下的所有子文件夹和聊天引用将被一并移除（但原始聊天记录仍存在于 AI 平台中，不会被删除）。

### 2.2 聊天管理

- **将聊天添加到文件夹**  
  在 AI 平台的原生对话列表中，右键（或点击更多菜单）中的“添加到文件夹”选项，会展开一个级联菜单，你可以选择目标文件夹（或子文件夹）完成保存。
- **从侧边栏直接访问聊天**  
  在扩展面板中，所有已保存的聊天会以链接形式展示，点击即可在当前平台中打开该对话（支持 SPA 无刷新切换）。
- **从文件夹中移除聊天**  
  鼠标悬停在聊天项上，点击出现的“🗑️”按钮即可从该文件夹中移除引用（不影响平台中的原始记录）。

### 2.3 平滑导航（SPA 适配）

- 点击侧边栏中的聊天链接时，扩展会优先尝试模拟点击平台原生导航元素，触发 SPA 的客户端路由切换。
- 若原生元素不可见，则使用 `history.pushState` + `popstate` 事件驱动，最大限度避免页面重载。

### 2.4 拖拽排序

- **文件夹/聊天均可拖拽**，灵活调整树结构。
- **放置位置判定**：
  - 拖到目标卡片的 **上方 20%** → 放置到目标**之前**。
  - 拖到目标卡片的 **中间 60%** → 放置到目标**内部**（成为其子节点）。
  - 拖到目标卡片的 **下方 20%** → 放置到目标**之后**。
- **防误操作**：禁止将父文件夹拖入自身或其子级，避免循环引用。
- **视觉反馈**：拖拽过程中会显示插入线、高亮背景等提示。

### 2.5 侧边栏面板

- **位置**：固定在浏览器窗口右侧，点击屏幕边缘的彩色小条即可展开/收起。
- **树形展示**：以缩进形式显示文件夹层级，每个文件夹前有折叠/展开按钮（▶/▼）。
- **操作按钮**：每个文件夹卡片均提供“添加子文件夹”、“编辑”、“删除”按钮，鼠标悬浮时出现。
- **聊天项样式**：以紧凑的列表形式显示，无多余装饰，仅保留标题和删除按钮。

### 2.6 原生菜单集成

- 在 ChatGPT、Gemini、Claude、DeepSeek 的对话列表或上下文菜单中，扩展会动态注入“添加到文件夹”选项。
- 鼠标悬停在该选项上时，会弹出一个级联菜单，展示当前用户的所有文件夹树，支持多级导航。
- 点击任一文件夹后，当前对话即被保存至该文件夹，并自动展开侧边栏并在新添加的节点上闪烁高亮。

## 3. 用户体验

- **深色模式适配**：全部 UI 采用深色主题，与主流 AI 平台的暗色风格协调。
- **平台专属颜色**：右侧的触发条（dock）颜色根据不同平台自动变化（ChatGPT 绿、Claude 橙、DeepSeek 蓝、Gemini 四色渐变），方便识别。
- **交互动画**：卡片 hover、菜单弹出、折叠展开均有平滑过渡。
- **新添加高亮**：当聊天被保存到文件夹时，对应的卡片会闪烁三次绿色光晕，帮助用户定位。

## 4. 技术实现

### 4.1 架构概览

采用 **适配器模式** 实现跨平台复用：

- **`LeftSidebarAdapter`**（基类）：定义统一接口（获取用户 ID、获取聊天信息、导航等），并提供级联菜单、菜单关闭定时器等通用逻辑。
- **平台子类**（`ChatGPTAdapter`、`GeminiAdapter`、`ClaudeAdapter`、`DeepSeekAdapter`）：各自实现平台特定的 DOM 选择器、事件捕获、账户识别和路由方案。

**UI 层**：
- **`RightSidebar`**：负责渲染面板、处理用户交互（点击、拖拽）、监听全局事件。
- **`FolderEditor`**：提供内联表单，用于创建/编辑文件夹。

**数据层**：
- **`FolderManager`**：单例模式，封装 `chrome.storage.local` 读写，提供 CRUD、排序、扩展/折叠状态管理等方法。

### 4.2 数据存储

- **存储引擎**：`chrome.storage.local`，保证数据持久化且仅本地存储。
- **存储键格式**：`acf_{platformId}_{sanitizedUserId}`，确保不同平台、不同账号的数据相互隔离。
- **数据结构**：以 `FolderData[]` 数组存储整个树，每个节点包含 `id`、`name`、`color`、`parentId`、`children`、`isCollapsed`、`isChat` 等字段。
- **聊天节点**：`isChat: true` 的叶子节点，仅保存 `id`、`title` 和 `url`（动态生成）。

### 4.3 平台适配细节

| 平台   | 用户 ID 获取方式                                   | 导航策略                                   | 菜单注入位置                    |
|--------|----------------------------------------------------|--------------------------------------------|-------------------------------|
| ChatGPT | 从 `#client-bootstrap` 脚本解析 `session.account.id` | 优先点击 `a[href*="/c/"]`，回退 History API | `[role="menu"] > div[role="group"]:last-child` |
| Gemini | 从 `<meta name="og-profile-acct">` 或 `WIZ_global_data` 提取 | 滚动加载历史列表并点击对应链接，回退全页跳转 | `div.mat-mdc-menu-content`    |
| Claude | 从 localStorage 的 `__qk_hint_account_uuid` 或通过 React Fiber 注入桥接（MAIN world） | 点击 `a[href*="/chat/"]`，回退 History API | `[role="menu"] div:first-child` |
| DeepSeek | 读取 `localStorage.userToken`，调用 `/api/v0/users/current` 获取 ID | 点击 `a[href*="/a/chat/s/"]`，回退 History API | `.ds-floating-position-wrapper .ds-dropdown-menu` |

**Claude 特殊桥接**：由于内容脚本处于孤立世界（ISOLATED world），无法直接访问 React Fiber 内部属性，因此通过注入 `claude-main-bridge.js`（运行于 MAIN world）来传递用户 UUID，采用事件驱动机制实现数据交换。

### 4.4 安全性

- **零权限访问**：扩展仅申请 `storage` 权限，无网络请求，不上传任何数据。
- **不存储聊天内容**：仅存储 `id`、`title` 和 `url`，且 `title` 仅用于显示，不依赖其进行导航。
- **账号隔离**：不同账号（同一平台）的存储键不同，互不干扰。

## 5. 注意事项

- **登录状态检测**：扩展仅在确认用户已登录后才激活，避免干扰未登录页面。
- **聊天删除同步**：若用户在 AI 平台中删除了某个对话，扩展侧边栏中的引用条目**不会自动删除**（因为平台没有提供删除通知）。但点击该条目时会因无法找到对应对话而失败，用户可手动移除。
- **浏览器兼容**：目前仅支持 Chrome/Edge（基于 Chromium）的 Manifest V3。Firefox 支持计划中。
